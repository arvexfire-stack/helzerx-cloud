# HelzerX Cloud

Premium, responsive cloud-hosting landing page built with React and Vite.

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

The marketing page uses CSS-built 3D server/cloud illustrations and includes responsive navigation, plan cards, interactive FAQ, and accessible motion preferences.

Before production launch, replace demo plan prices and performance figures with verified current service data, connect the CTAs to real provisioning/checkout endpoints, and publish accurate Terms, Privacy, and Acceptable Use policies.
